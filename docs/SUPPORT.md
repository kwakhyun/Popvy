# Popvy 지원

Popvy는 macOS 13 이상에서 실행되는 클립보드 기록 앱입니다. 현재 앱 화면은 한국어입니다.

## 사용 방법

1. Popvy를 실행합니다. 메뉴 막대에 클립보드 아이콘이 표시됩니다.
2. 다른 앱에서 텍스트나 이미지를 복사합니다.
3. Option+V를 눌러 기록을 엽니다.
4. App Store용 버전에서는 원하는 항목을 선택한 뒤 원래 앱에서 Command+V로 붙여넣습니다. GitHub 버전은 손쉬운 사용 권한을 허용하면 바로 붙여넣을 수 있습니다.

검색은 Command+F, 항목 선택은 방향키와 Return, 닫기는 Esc입니다. 항목 메뉴에서 고정과 삭제를 할 수 있습니다.

## 문제가 있을 때

- 단축키가 반응하지 않으면 메뉴 막대 아이콘으로 열고, 설정에서 다른 단축키를 선택하세요. 두 배포 버전을 동시에 실행하지 마세요.
- 기록이 쌓이지 않으면 기록 일시 정지 상태와 macOS의 클립보드 읽기 허용 여부를 확인하세요. 민감한 내용으로 표시된 항목, 파일 복사, 항목당 5 MiB를 넘는 내용은 수집하지 않습니다.
- App Store용 버전은 손쉬운 사용 권한 없이 복사와 수동 붙여넣기로 동작합니다. 자동 붙여넣기 설정이 없는 것은 정상입니다.
- 기록을 지우려면 설정에서 ‘모든 기록 삭제’를 선택하세요. 디스크 보관만 끄려면 ‘앱을 종료해도 기록 보관’을 끄세요.
