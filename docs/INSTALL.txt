Popvy (팝비) 1.3.0 — 설치 안내

macOS 13 이상 / Apple Silicon 및 Intel

1. Popvy.app을 Applications(응용 프로그램) 폴더로 드래그합니다.
   ZIP을 받았다면 압축을 푼 앱을 같은 폴더로 옮기세요.
2. DMG를 사용했다면 디스크 이미지를 추출합니다.
3. 응용 프로그램 폴더에서 Popvy를 실행합니다.
4. 첫 안내에서 '시스템 설정 열기'를 누르고 손쉬운 사용의 Popvy를 켭니다.
   필요한 인증은 Mac에서 직접 완료하세요.
5. 허용이 감지되면 'Popvy 시작하기'를 누릅니다.
6. 텍스트나 이미지를 복사하고, 입력란에서 Option + V를 눌러 기록을 고릅니다.

앱은 Dock 대신 메뉴 막대에 표시됩니다.
권한은 나중에 허용해도 됩니다. 그동안은 항목 선택 후 Command + V로 붙여넣으세요.

첫 실행이 차단되면
현재 배포본은 Apple Developer ID 서명과 공증이 없는 임시 서명 빌드입니다.
출처를 확인하고 실행하기로 결정했다면 한 번 실행을 시도한 뒤
시스템 설정 → 개인정보 보호 및 보안 → '그래도 열기'를 사용하세요.
https://support.apple.com/ko-kr/102445

권한을 켰는데도 인식하지 못하면
손쉬운 사용 목록에서 Popvy를 제거한 뒤 + 버튼으로 현재 설치된 앱을 다시 추가하세요.
업데이트할 때는 Popvy를 먼저 종료하고 앱을 교체하세요. 기록과 설정은 유지됩니다.

기록은 이 Mac에 저장하며 서버로 전송하지 않습니다. 앱 수준 암호화는 없습니다.
일반 텍스트로 복사한 비밀번호까지 자동으로 판별하지는 않습니다.
민감한 내용을 복사하기 전 메뉴에서 기록 수집을 일시 정지할 수 있습니다.
