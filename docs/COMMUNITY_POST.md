# 윈도우에서 쓰던 Win+V가 생각나서, Codex와 맥용 클립보드 앱을 만들었습니다

윈도우에서 복사 기록을 꺼내 쓰는 Win+V를 자주 썼습니다. 맥에서도 단축키를 누르면 작은 목록이 뜨고, 필요한 내용을 골라 바로 붙여넣을 수 있으면 좋겠더라고요. 그래서 Codex와 함께 **Popvy(팝비)**라는 맥용 앱을 만들었습니다.

처음 요청은 단순했습니다. “Option+V로 열고, 커서 옆에 뜨고, 누르면 바로 입력되게 해줘.” 실제로 써 보면서 창을 더 작게 바꾸고, 검색과 항목 고정도 넣었습니다. 복사한 텍스트와 이미지는 최근 100개까지 보관합니다.

만드는 동안 의외로 신경 쓸 게 많았던 건 macOS 권한이었습니다. 다른 앱에 자동으로 붙여넣으려면 사용자가 손쉬운 사용 권한을 허용해야 하고, 앱을 업데이트한 뒤 권한이 다시 연결되지 않는 문제도 겪었습니다. 처음 실행할 때 설정으로 안내하고, 허용 여부를 자동으로 감지하도록 고쳤습니다. 업데이트할 때 권한이 풀리는 문제는 정식 서명으로 개선하는 작업을 진행 중입니다.

클립보드에는 개인적인 내용도 들어가니 계정이나 서버 없이 Mac 안에서만 동작하게 했습니다. 기록을 디스크에 남기지 않는 설정도 있습니다. 다만 일반 텍스트로 복사한 비밀번호를 자동으로 알아내는 기능은 없어서, 민감한 작업을 할 때는 기록을 잠시 멈추는 게 좋습니다.

지금은 GitHub에 **무료 오픈소스(MIT)**로 공개했습니다. macOS 13 이상에서 사용할 수 있고, Apple Silicon과 Intel을 모두 지원합니다. 현재 1.3.1은 Apple 공증 전이라 첫 실행 때 macOS 보안 안내가 나올 수 있습니다. 설치 방법도 README에 적어 두었습니다.
