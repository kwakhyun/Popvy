# Popvy 1.3.1

첫 실행 권한 안내를 더 쉽게 따라갈 수 있도록 개선했습니다.

## 달라진 점

- 설정 열기 → Popvy 허용 → 단축키 사용의 3단계를 표시합니다.
- 현재 단계는 강조하고, 완료한 단계에는 체크 표시를 보여줍니다.
- 권한 승인 대기 상태와 완료 상태를 구분하고, 완료 후 단축키 사용법을 안내합니다.
- 권한의 용도를 설명하고 문제 해결 도움말을 필요할 때 펼쳐볼 수 있습니다.
- 앱 아이콘, 제목 표시줄과 버튼을 다듬었습니다.
- 중복 다운로드를 줄여 설치 파일을 DMG 하나로 제공합니다.

## 설치

1. 아래 **Popvy-1.3.1-macos-universal.dmg**를 다운로드합니다.
2. DMG를 열고 **Popvy.app을 Applications 폴더로 드래그**합니다.
3. 설치된 앱을 실행하고 화면 안내에 따라 손쉬운 사용 권한을 허용합니다.

macOS 13 이상, Apple Silicon과 Intel을 지원합니다. 앱 화면은 한국어입니다. 소스는 GitHub의 **Source code** 링크에서 받을 수 있습니다.

**현재 배포본은 Apple Developer ID 서명과 공증이 없는 임시 서명 빌드입니다.** macOS가 첫 실행을 차단할 수 있습니다. 출처를 확인하고 실행하기로 결정한 경우의 절차는 [설치 안내](https://github.com/kwakhyun/Popvy#설치)와 [Apple 지원 문서](https://support.apple.com/ko-kr/102445)를 참고하세요.

업데이트할 때는 실행 중인 Popvy를 먼저 종료한 뒤 앱을 교체하세요. 기록과 설정은 유지됩니다. 권한이 인식되지 않으면 손쉬운 사용 목록에서 Popvy를 제거한 뒤 현재 설치된 앱을 다시 추가해 주세요.

Apple Silicon Mac에서 개선된 화면을 확인했습니다. Intel용 코드의 빌드 및 포함 여부를 검사했으며, Intel과 macOS 13 실기기 실행은 검증하지 않았습니다.

다운로드 파일과 SHA256SUMS.txt를 같은 폴더에 두고 `shasum -a 256 -c SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.
