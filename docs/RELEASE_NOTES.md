# Popvy 1.3.0

Option + V로 커서 옆에서 여는 macOS 클립보드 기록 앱입니다.

## 이번 버전

- 첫 실행에서 자동 붙여넣기 권한을 안내합니다.
- 버튼으로 손쉬운 사용 설정을 열고, 허용되면 자동 감지해 붙여넣기를 켭니다.
- 나중에 설정할 수 있으며, 권한이 인식되지 않을 때의 해결 방법도 안내합니다.
- Apple Silicon과 Intel 실행 파일을 포함한 DMG와 ZIP을 제공합니다.

## 다운로드

| 파일 | 용도 |
| --- | --- |
| `Popvy-1.3.0-macos-universal.dmg` | 권장 설치 파일. 앱을 Applications로 드래그하세요. |
| `Popvy-1.3.0-macos-universal.zip` | 앱만 압축한 대체 다운로드 |
| `Popvy-1.3.0-source.zip` | 개발용 소스 코드 |
| `INSTALL.txt` | 설치와 권한 설정 안내 |
| `SHA256SUMS.txt` | 다운로드 무결성 확인용 SHA-256 체크섬 |

macOS 13 이상이 필요합니다. 현재 앱 화면은 한국어입니다.

**이 배포본은 임시 서명 빌드이며 Apple Developer ID 서명과 공증을 받지 않았습니다.** 첫 실행이 차단될 수 있습니다. 출처를 확인하고 실행하기로 결정한 경우의 절차는 설치 안내와 [Apple 지원 문서](https://support.apple.com/ko-kr/102445)를 참고하세요.

Apple Silicon Mac에서 검증했습니다. Intel용 코드의 빌드 및 포함 여부는 확인했지만 Intel 실기기 실행과 macOS 13 실기기 검증은 아직 하지 않았습니다.

업데이트할 때는 실행 중인 Popvy를 먼저 종료하세요. 기록과 설정은 유지됩니다. 손쉬운 사용 권한을 다시 설정해야 할 수 있습니다.
