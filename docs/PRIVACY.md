# Popvy 개인정보 처리방침

최종 수정: 2026년 10월 16일

Popvy는 복사한 텍스트와 이미지를 Mac 안에서 다시 꺼내 쓰는 클립보드 기록 앱입니다. 개발자는 앱을 통해 클립보드 내용, 사용 기록, 기기 식별자 또는 진단 정보를 수집하거나 전송받지 않습니다. 계정, 광고, 분석 도구, 서버 전송과 클라우드 동기화 기능이 없습니다.

## Mac에서 처리하는 정보

앱이 실행 중이고 기록 수집이 활성화되어 있을 때, 클립보드가 변경되면 텍스트와 이미지, 텍스트의 HTML/RTF 서식, 복사 시각, 원본 앱 이름을 처리합니다. 이 정보는 기록 표시, 검색, 고정과 다시 복사하기에 사용합니다. 파일 복사는 수집하지 않습니다.

기록은 최근 100개, 전체 50 MiB, 항목당 5 MiB 이내로 보관하며 최대 20개를 고정할 수 있습니다. 보관 한도를 넘으면 고정하지 않은 오래된 항목부터 정리합니다.

## 저장과 삭제

‘앱을 종료해도 기록 보관’을 켜면 Mac의 앱 데이터 폴더에 저장합니다. GitHub 배포본은 `~/Library/Application Support/Popvy`를 사용하고 App Store용 빌드는 자체 샌드박스 컨테이너 안에 저장합니다. 두 버전의 기록은 자동으로 동기화되지 않습니다.

기록 파일은 해당 사용자만 읽고 쓸 수 있도록 만들지만 앱 수준 암호화는 적용하지 않습니다. Mac의 다른 보안 설정이나 사용자가 만든 백업의 보호 수준은 별개입니다.

- 항목 메뉴에서 개별 기록을 삭제할 수 있습니다.
- 설정의 ‘모든 기록 삭제’는 고정 항목까지 삭제합니다.
- ‘앱을 종료해도 기록 보관’을 끄면 디스크의 기록 파일을 삭제하고 실행 중 메모리에서만 보관합니다.
- ‘기록 일시 정지’를 선택하면 새 내용을 수집하지 않습니다.

Popvy 기록을 삭제해도 macOS 시스템 클립보드에 남아 있는 내용이나 별도로 만든 백업까지 삭제되지는 않습니다.

## 민감한 내용과 권한

비밀번호 관리 앱이 민감한 데이터로 표시한 항목은 수집 대상에서 제외합니다. 일반 텍스트로 복사한 비밀번호나 인증번호까지 자동 판별하지는 않습니다. 민감한 작업 전에는 기록 수집을 일시 정지할 수 있습니다.

GitHub 배포본은 사용자가 손쉬운 사용 권한을 허용하면 입력 위치를 확인하고 선택한 기록을 원래 앱에 붙여넣습니다. App Store용 빌드는 이 권한을 요청하지 않으며, 항목 선택 후 사용자가 직접 Command+V로 붙여넣습니다. macOS가 클립보드 읽기 허용을 요청할 수 있습니다.
