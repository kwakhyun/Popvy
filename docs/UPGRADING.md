# 업데이트와 ClipShelf에서 이전

## Popvy 업데이트

1. 메뉴 막대의 Popvy를 오른쪽 클릭해 종료합니다.
2. 새 배포 파일의 앱으로 응용 프로그램 폴더의 앱을 교체합니다.
3. 다시 실행합니다. 기록과 설정은 유지됩니다.

임시 서명 빌드는 업데이트 후 손쉬운 사용 권한을 다시 설정해야 할 수 있습니다. 스위치가 켜져 있는데도 인식하지 못하면 권한 목록에서 제거한 뒤 현재 앱을 다시 추가해 주세요.

## ClipShelf 사용자

1. 이전 앱에서 로그인 시 자동 실행을 사용했다면 먼저 끄고 ClipShelf를 종료합니다.
2. Popvy를 설치하고 실행합니다.
3. Popvy의 손쉬운 사용 권한과 로그인 시 자동 실행을 새로 설정합니다.

Popvy는 이전 복사 기록, 고정 항목, 단축키, 자동 붙여넣기 및 기록 보관 설정을 한 번 이어받습니다. 기존 Popvy 기록이나 설정이 있으면 그것을 우선합니다.

`~/Library/Application Support/ClipShelf/history.json`은 새 Popvy 폴더로 이동합니다. 기록 보관을 꺼 둔 경우 가져오지 않습니다. 이전에 실패하면 원본 위치를 사용하고 다음 실행 때 다시 시도합니다. macOS 권한은 자동 이전하지 않습니다.
